# 项目目标：极简、一切皆插件、企业能力可长出的 agent 系统

Atom Agent 的仓库级目标不是「做一个自己用的 REPL」，而是自研一套可插拔 agent 系统，同时吃下三条原则、不 fork 任何一家：

- **pi 的极简**：循环小，产品（TUI、默认工具、权限）不焊进内核。
- **DeepSeek Harness 的一切皆插件**：宿主可换循环；能力按契约挂上。运行时用官方 Cordis。
- **AgentScope 2.0 的企业级能力**：可观测、会话、沙箱、可嵌入 Runtime、多智能体等靠加槽长出，不预埋进核。

v0 只交付自己用的 coding CLI（流式 REPL），用来钉死内核与插件契约。企业能力是后续阶段，不是 v0 范围，也不是「做完 v0 项目就结束」。
