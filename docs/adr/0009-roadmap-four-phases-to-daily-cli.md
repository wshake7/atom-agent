# 到日常 CLI 闭环共四段，记忆不进退出条件

v0 产品闭环之后的实现路线图切成四段：装配与配置 → 跨进程会话 → 长上下文（压缩）→ Skill · 兼容包 · REPL 手感。最后一段退出即 **日常 CLI 闭环**。不收成一行无法交接的愿望，也不按能力簇拆成六段假流水线——最后三簇没有互相的硬依赖，并成一段验收。压缩改下一轮模型可见历史，会话日志不因此只剩压缩稿；跨会话记忆（旁路存储）本段明确没有。允许为某段退出条件要求的能力点名新官方槽，禁止预埋空槽；不改 `loop` / `tools` / `llm` 语义，不加内核第五件套。对照 [ADR-0005](./0005-roadmap-six-phases-to-v0.md)。
