# 内核最小闭合集

Type: grilling
Label: wayfinder:grilling
Triage: ready-for-human
Status: resolved
Blocked by: 01, 02, 03

## Question

我们的**内核**里必须留下什么、其余全部降为插件？

对照三份调研（pi 的「小」、Harness 的「可替换」、AgentScope 的「不要过早进核」），锁死最小闭合集。至少裁定：

- 回合循环、消息类型、工具执行器、流式与取消，谁在核内。
- 模型调用是核内端口还是插件。
- 会话对象是否在核内；持久化是否只是接缝。
- 一条检验标准：删掉 X 之后还能否称为 agent 内核。

本票只锁不变量，不锁插件清单，不锁 CLI 产品形态。

## Answer

内核是插件宿主，不是回合循环（ADR：[内核是插件宿主，不是回合循环](../../../docs/adr/0001-kernel-is-plugin-host.md)）。闭合集只有四件：服务注册、依赖注入、生命周期（加载 / 卸载 / 可逆 effect）、事件总线原语（发布 / 订阅）。业务事件名、发现与组成、boot、模型调用、工具执行、会话对象与持久化都不在核内。

回合循环是可整颗替换的循环插件。「删掉则无法完成一次模型 ↔ 工具回合」用来检验循环插件的闭合集，不用来检验内核。循环插件内部（消息类型、调度、流式与取消、模型端口）见 [默认循环插件最小闭合集](./10-default-loop-plugin-closed-set.md)。
