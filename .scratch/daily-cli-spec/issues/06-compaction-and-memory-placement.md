## Answer

**压缩**挂在新官方槽 `compact` 上，不进默认**循环插件**闭合集。**记忆**不挂槽、本图不点名记忆槽。

- 压缩与记忆是两件事（前序：[日常 CLI 闭环的退出条件](./05-daily-cli-exit-criteria.md)）。记忆已划出本图。
- 默认循环闭合集不扩：压缩仍在循环外，换循环不必带走压缩。`loop` / `tools` / `llm` 语义不变。不改写 v0 规格，不改 [ADR-0006](../../../docs/adr/0006-default-loop-plugin-closed-set.md) 的闭合集。
- 默认循环合同只加可选消费：每次请求 `llm` 前，若 Context 上有 `compact` 提供方，就把当前内存消息列表交给它，用返回值作为模型可见视图；没有提供方则恒等。是否真缩短，由提供方决定。
- 官方槽 `compact`：把内存消息列表映射成送给模型的更短视图。不改原列表，不写盘。贡献方是循环之外的插件；日常 CLI 默认装配会装上一颗（不是空槽）。消费方是默认循环（可选）；自定义循环可以不消费。
- v0 仍是三个官方槽。术语表已改：**槽**列出日常 CLI 新增的 `compact`。

明确没有：算法、触发阈值、提示词模板、记忆库、落盘格式。触发与「压什么」见后续票。
