## Question

重启进程后，**哪些会话状态必须还在**，合同挂在哪一层？

前序：[跨进程会话常见合同](./03-session-persistence-in-coding-agents.md)。v0 默认循环只有内存消息列表。

至少裁定：

- 最小落盘集（消息？推理块？工具结果？配置快照？）
- 恢复面：启动默认最近一次、按工作目录、还是显式选会话
- 持久化是循环插件的事、CLI 的事、未点名键，还是新官方槽
- 和压缩 / 记忆是否共用存储（可链 [压缩与记忆挂在哪](./06-compaction-and-memory-placement.md)，不在本票设计压缩）
- 明确没有：存储引擎选型、加密、多机同步

不写代码。

## Answer

跨进程会话挂在新官方槽 `session` 上：落盘**会话日志**，供溯源回放与续聊。记忆不共用这份日志；本图不设计记忆库。

- **槽 `session`**：跨进程读写会话日志。贡献方是循环外的插件；日常 CLI 默认装配装上一颗（不是空槽）。未点名键仍允许。`loop` / `tools` / `llm` 语义不变。名单汇总见 [本阶段点哪些官方槽](./12-official-slots-this-stage.md)。
- **默认循环可选消费**：有提供方则**追加**终态消息与压缩事件；没有则纯内存。不进闭合集，换循环可以不消费。持久化实现仍不在这颗循环插件里（[ADR-0006](../../../docs/adr/0006-default-loop-plugin-closed-set.md)）。
- **CLI / REPL 消费进程边界**：新建、按 id 打开、当前 cwd 最近一次、列表。裸启动永远新会话。斜杠名留给 [REPL 手感最小集](./10-repl-feel-minimum.md)。
- **最小落盘集**（重启后必须还在，可溯源回放）：三角消息 `user` / `assistant` / `toolResult`（含推理块、`toolCall`、工具参数与结果、`isError`）；同一份日志里的**压缩事件**（摘要 + 切点），原文仍在；每条 `assistant` 的提供商 / 模型（写盘时盖当时装配里的标识，不改 `llm` 槽）；时间戳。日志带 cwd 只为索引。
- **时机**：内存列表每追加一条终态消息、或产生一次压缩事件，就同步追加。不写流式增量。
- **恢复**：CLI 从 `session` load 原文消息，交给默认循环**工厂**的可选初始列表。`Loop` 仍是 `messages` + `prompt`，不加 `hydrate`。下次请求仍把恢复后的原文列表交给 `compact`；压缩事件只用来回溯当时模型看到的视图。
- **压缩**：`compact` 槽仍不写盘。压缩事件由循环写入会话日志，不是压缩提供方写盘。
- **续聊装配**：不冻配置。新回合跟当前装配走。

明确没有：配置快照 / 冻结 MCP 与工具开关、半截流、Abort 的半截助手、文件 checkpoint、记忆库、加密、多机同步、存储引擎与路径格式。

术语表已改：**会话**、**会话日志**、**压缩事件**；**槽**列出日常 CLI 新增的 `session`。
